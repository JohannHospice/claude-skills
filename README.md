# Skills Claude de Johann | Tech

Des skills gratuits pour les développeurs qui passent freelance. Par [@techwithjohann](https://www.instagram.com/techwithjohann/).

## 30 recruteurs

Ton CV de développeur freelance lu par 30 recruteurs d'ESN simulés, chacun avec un vrai besoin (secteur, stack, TJM, télétravail, urgence). Tu sais combien te rappellent, pourquoi les autres non, et la première chose à changer sur ton CV.

**Dans Claude Code :** colle ce lien et dis « installe ce skill » :

```
https://github.com/JohannHospice/claude-skills/tree/main/30-recruteurs
```

Ou à la main : copie le dossier `30-recruteurs` dans `~/.claude/skills/`.

**Dans Claude (claude.ai ou l'app) :** Paramètres → Capacités → Skills → importer [`30-recruteurs.zip`](30-recruteurs.zip).

**Sans installer :** ouvre [`30-recruteurs/SKILL.md`](30-recruteurs/SKILL.md), copie le texte sous le titre dans une conversation avec Claude, puis colle ton CV en dessous.

Ensuite : « Teste mon CV », avec ton CV collé ou joint.
